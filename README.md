# Pan-Prostate Cancer Group (PPCG) driver analyses

This repository contains the software and analysis code used for the publication

***The molecular heterogeneity and clinical impact of genomic driver alterations in prostate cancer***

by Pellegrina D, Kiriy D, Cheng K *et al.* (2026). 

The repository contains the analysis workflow used to identify recurrent genomic alterations (RGAs), perform downstream statistical analyses, and generate the figures and supplementary figures in the publication. The primary workflow consists of sequentially executed R scripts numbered **001-007**, corresponding to data preparation, driver discovery, clinical analyses, clustering, visualisation, and external validation. Additional scripts numbered **100+** implement specialised analyses and figure panels. Utility scripts shared across multiple analyses are also included.

## Running the analyses

The analysis scripts are designed to be run sequentially, as later steps depend on intermediate data and results generated by earlier steps. The numbered scripts (001-007) therefore represent the analysis workflow rather than independent figure-generation scripts. The figure-specific scripts listed below should be run only after the required preceding steps have been completed. Scripts numbered 100+ perform specialised downstream analyses and figure generation and may depend on outputs or functions produced by earlier scripts.

The table below lists the scripts used to generate each main and supplementary figure.
